# Lczz
武汉力创之尊项目，后台管理系统以及微信小程序端

## 当前联调与一期边界

- 开发与生产环境统一使用 `https://admin.whlczz.cn/api/v1`，环境变量未加载时也回退到该线上地址。
- 微信开发者工具和正式包均开启合法域名校验；需在微信公众平台将 `https://admin.whlczz.cn` 配置为 request、uploadFile（如使用）合法域名。
- 一期不提供资讯动态、购物车、线上购买、支付和小程序内创建订单。
- 小程序已移除虚拟登录和业务 Mock 数据，联调与发布包均只请求真实后端。
- 产品页仅展示后端 `/consumables/**` 数据，订单和个人页仅展示当前角色可见的真实数据。
- 发布前必须确认 `request`/`uploadFile` 合法 HTTPS 域名及图片选择隐私声明均已配置。


鑫立创业务系统说明
一、注册认证
小程序内通过手机号一键注册登录。

二、业务流程
1. 经销商发起安装任务（线下）
通过打电话或者发信息的方式通知管理员录入任务信息。
2. 创建任务
接到经销商任务信息，管理员后台创建任务。
创建订单字段：
•任务类型
•省市区（选择）+ 详细地址
•描述
•客户姓名
•客户手机号
•订单要求时间
•指派师傅
•附件（图片）

创建订单界面


3.指派师傅
加一个备注(标注师傅状态等内容，在用户管理修改)

指派师傅界面

4. 师傅上门
师傅打电话联系终端客户，商量上门时间（线下）。
师傅让客户注册小程序，客户通过手机号登录小程序后，与客户手机号对应的订单会自动绑定在客户小程序内，客户即可在小程序上查看订单。
订单状态	代码	描述
待上门	1	管理员创建订单，此时状态为待上门
处理中	2	安装师傅上门，在小程序下单需要的耗材，此时状态变为处理中
已完成	3	订单绑定客户确认完成后，施工进度封存，此时状态变为待评价；评价后仍属于已完成
已评价	4	客户在订单内完成评价后，此时状态变为已评价

客户小程序订单界面


客户小程序详情界面


5. 施工完成提交（空调安装多天需要每天上传进度给客户看到）
师傅对需要用的产品下单，线下帮客户完成安装，完成后上传施工图片并描述提交。

师傅提交施工界面


添加使用工具界面




6. 客户评价
客户可以点赞、评价。

客户评价界面

注：收费是线下的，不在小程序中处理。



三、鑫立创后台管理系统
1. 订单管理
集中展示所有空调安装订单信息，支持按关键词搜索、批量导出数据和新增订单操作。管理员可对每条订单进行编辑和删除，实现订单的全生命周期管理。

任务列表界面












2.订单备货
展示所有空调安装的师傅申请的耗材列表，支持按关键词搜索。管理员可对每条申领情况进行领取和作废操作。






耗材管理
展示所有空调所需的耗材列表，支持按关键词搜索以及添加、修改和删除。管理员添加耗材并选择所属类型，展示在小程序的产品页面。
