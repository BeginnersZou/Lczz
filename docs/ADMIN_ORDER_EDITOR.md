# 后台订单统一编辑（Issue 155）

## Work Packet

- 目标：订单修改页统一编辑基础信息、订单附件、已有施工说明/图片及当前有效的工程耗材清单。
- 基线：最新 `dev`，包含 Issue 154 的北京时间契约；分支 `codex/issue-155-order-editor`。
- 影响：后台 OrderForm 与独立图片/耗材编辑组件，后台管理员编辑接口，以及订单、文件、施工进度、耗材共享服务。
- 状态：用户已确认管理员可以更正待评价/已评价订单，保留完成状态、客户确认记录、原施工师傅及提交时间；CANCELLED 只读。师傅仍受客户确认后的封存限制。
- 耗材：实际变更品种、SKU 或数量会将申请重置为 PENDING，清除旧备货结果；只改备注或未改清单保留状态和库存。完成订单也遵守此规则，订单状态不回退。
- 接口：新增管理员专用 GET/PUT `/api/v1/admin/orders/{id}/editor`。一次 PUT 在同一事务中保存所有板块；可省略未修改板块。版本摘要覆盖订单、施工、附件、申请和备货明细；提交标识用于失败重试去重。
- 数据库：复用既有业务表和 operation_audit_log，记录实际管理员及修改前后数据、库存变化，不需要 Flyway 迁移。
- 验证：后端集成测试覆盖权限、封存边界、图片归属/顺序、库存、备货重置、并发及回滚；运行实际 Vue 组件回归、后台生产构建及现有相关测试。
- 回滚：回退本次后端和后台构建；数据库结构不变，已保存业务更正通过同一管理页面再次更正并保留审计。

## 接口约定

GET 返回 `order`、`progress`、`materialRequest`、`revision`、`editable` 和 `lastEdit`。`materialRequest` 仅包含 PENDING/PREPARING/DONE 的当前工程申请；历史作废申请继续在只读详情展示。`lastEdit.editedAt` 为带时区的北京时间，施工提交时间保持原来源的时间契约。

PUT 请求示例（未修改板块直接省略）：

```json
{
  "requestId": "b9a25c86-626d-47a8-bd23-338cc517305e",
  "revision": "GET 返回的 64 位摘要",
  "progress": [{ "id": 12, "description": "更正施工说明", "fileIds": [31, 32] }],
  "materials": {
    "items": [{ "productId": 4, "skuId": 8, "quantity": 3 }],
    "remark": "请重新核对备货"
  }
}
```

- `order` 使用原基础信息编辑请求字段；`attachmentFileIds` 为订单附件的完整有序文件 ID 列表。
- `progress` 只传实际修改的记录；每条保留原 ID、师傅和提交时间。传入 `fileIds` 时为该条记录完整有序的附件列表，省略时保留原附件。
- 每条施工记录最多30张图片和9个视频，分别计数；图片每张最多10MB。PC图片编辑与小程序施工提交、管理员追加统一使用此上限。订单原始附件仍最多9个。
- 新增/替换图片必须使用当前管理员上传的未关联文件；保留已有附件可继续使用原文件 ID。删除仅解除当前关联，保留实际文件和其它业务引用。
- `materials.items=[]` 表示清空当前清单：原申请转为 VOIDED 并释放预占，历史明细保留；省略 `materials` 表示完全不改耗材。
- 每次新修改使用新 requestId；超时且请求内容未改变时重用该 ID。相同请求成功重试不会再次修改库存或创建业务数据。
- 版本冲突返回 `409 ORDER_EDIT_CONFLICT`；已作废返回 `409 ORDER_NOT_EDITABLE`；图片跨订单/借用文件被拒绝；库存不足会回滚本次所有板块及审计。
- 库存变化在 operation_audit_log 中以 `ORDER_MATERIAL_STOCK_CHANGE` 记录 SKU 和变更前后库存；统一修改以 `ORDER_ADMIN_EDIT` 记录管理员、时间、提交标识和变更前后业务快照。日志不存完整客户手机号。

## 验证与人工验收

自动化覆盖整单保存失败回滚、并发相同提交去重/不同提交冲突、完成状态与客户确认及评价保留、原师傅归属和提交时间、图片排序及共享文件保护、库存与预占、仅备注不重置备货、清空清单和未申请时新增。后台检查运行实际编译的 Vue 组件，验证回显、草稿、失败上传重试、筛选/选 SKU、备货提示、取消前不保存及冲突重载。

微信真机和开发者工具不在本机，师傅小程序内的最终展示保留为人工验收；接口回归需验证同一订单从师傅接口读取到最新施工和耗材数据。
