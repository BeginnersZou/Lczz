# Issue #184 Worker：PC 管理端列表与表格视觉规范

基线：`origin/dev@ca5b4e35`；工作分支：`codex/admin-table-design-system-20261014`。

## 问题与目标

当前页面同时使用多套表格、操作按钮和分页样式。`border stripe` 形成密集网格，宽达 180–330px 的固定右侧操作列在中小屏遮盖内容；列表卡片、筛选卡片和分页的位置互不一致。项目案例尤为明显：右侧操作列、右贴边的分页和留白失衡。

## 实施范围

1. 建立统一的列表表格视觉令牌和行操作组件，覆盖订单、耗材、用户、备货、案例；保留业务事件与权限判断。
2. 移除列表常驻固定右侧操作列，以「主操作 + 更多菜单」收敛宽度；危险操作明确标识，菜单支持键盘操作。
3. 统一页头、筛选、列表容器、空状态和分页的节奏及边距，并改善窄屏时的水平滚动提示。
4. 审核表单/详情内嵌表格，避免全局样式破坏其输入密度；检查其它明显不一致的 PC 页面样式。

本次是 PC 展示与操作布局重构，不改变接口、鉴权、业务状态机和后端持久化；如触及业务逻辑，需扩展后端及其测试。

## 验收

- 订单、耗材、用户、备货、案例操作入口风格一致，原有操作均可达；无固定列遮挡正文。
- 小屏/中屏/大屏页面不产生意外的根级横向溢出；表格可预期地在自身区域滚动。
- 分页不贴边，筛选与列表卡片间距统一；无数据、失败和加载状态可辨认。
- PC 构建、现有页面流程测试与浏览器尺寸检查通过。

## 完成记录

- 订单、耗材、用户、备货、案例五个列表改用共享 `AdminRowActions`：常用操作直接显示，次级/危险操作进入“更多操作”；原有业务处理函数与权限条件保持不变。
- 删除大面积表格网格线、斑马纹与右侧固定操作列；统一表头、行高、卡片间距、分页内边距和按钮层级。窄屏表格显示常驻水平滚动条，避免右侧操作无法发现。
- 表单、详情和选择师傅弹窗的内嵌表格未套用列表类样式，保留其原有数据编辑密度；本任务没有修改接口、权限、业务状态机或后端代码。
