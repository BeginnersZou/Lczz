# 购物车收货信息与常用地址

安装师傅可以从购物车顶部填写本次收货信息，或选择常用地址；也可以在“我的 → 常用地址”提前维护地址。地址支持多份、编辑、删除和设置默认项。没有默认地址时不自动选择其它地址，仍可手动填写。

本次收货信息与地址本分开保存。默认地址只在本次尚未填写收货信息时预填；临时修改不会覆盖常用地址。保存为常用地址是可选操作。

下单前必须填写收货人、联系电话、完整收货地址。姓名最多64个字符，地址最多500个字符；电话支持国内手机号及带区号的固定电话。前后端都会校验，提交确认展示商品规格种数和三个收货字段。

## 接口

以下接口继续限定为安装师傅，只能读取和操作本人地址。请求前缀为 `/api/v1/installer`，旧 `/api/installer` 前缀也支持。

- `GET /addresses`：常用地址列表，默认项优先。
- `POST /addresses`：创建地址。
- `PUT /addresses/{id}`：更新地址。
- `PATCH /addresses/{id}/default`：设为默认地址。
- `DELETE /addresses/{id}`：删除地址。

创建和更新地址包含 `recipientName`、`recipientPhone`、`recipientAddress` 和 `isDefault`。同一用户的地址写操作锁定用户行，保证并发操作最多保留一个默认项。删除默认项后，可重新选择或设置默认地址。

`POST /self-orders` 保留 `requestId`，增加三个必填字段：

```json
{
  "requestId": "unique-request-id",
  "recipientName": "收货人",
  "recipientPhone": "13800000000",
  "recipientAddress": "省市区、街道和门牌号"
}
```

接口保存订单收货信息快照，不依赖地址本 ID。之后删除地址、修改账号或地址，不会影响历史订单。师傅订单详情、后台备货详情、单据明细导出和筛选结果导出均能读取该快照。

同一师傅的下单操作锁定用户行，并继续按 `requestId` 幂等。网络失败后购物车保留本次提交内容及标识，可重试；结果未知时锁定本次耗材和收货信息，即使服务器已清空购物车，仍可用原标识确认结果。明确的业务校验失败允许修改后重新提交。重复提交返回首次订单，不改写快照，也不重复发送通知。

## 上线

需要更新后端、后台管理系统及小程序，执行 Flyway `V14__installer_recipient_addresses.sql`，新增常用地址表和订单快照字段。历史订单字段允许为空，详情显示“未填写”。本迁移不改写历史订单、库存、已有地址或手机号配置。

新下单接口不接受仅有 `requestId` 的旧请求。应协调后端与小程序发布；旧小程序需更新后才能填写收货信息并继续下单。若服务器禁用了 Flyway，必须先按数据库发版流程应用 V14 再启用新版后端，避免缺表或缺列。

此功能不增加小程序管理员的全平台取货订单访问权限，也不改变工程订单耗材申请和备货权限。
