# 全栈：项目经理小程序全量订单只读权限

## 目标

- 项目经理仅使用小程序手机号登录，可查看全部未删除订单、进度、耗材及允许的附件。
- 项目经理没有任何订单或其他业务写权限。搜索/筛选/翻页/查看属于只读操作；误触写入口弹窗“无操作权限”，后端对任意写请求返回 403。
- 客户评价及评价附件维持仅管理员可见，不能因全量订单读取而泄露。

## 技术范围

- 订单列表全量范围和专用只读详情 DTO；不要直接开放含客户评价的管理员详情聚合接口。
- 进度、耗材、订单附件/进度附件及签名访问鉴权同步为只读范围；评价资源仍拒绝。
- 小程序会话识别和订单页只读态；禁用/隐藏写入口，并在深链或异常操作时弹窗；403 不重定向登录。
- PC 账号密码登录保持管理员专用，不给项目经理开放 PC 后台。

## 验收

项目经理能查所有订单及合法附件，但无法读取任何客户评价；逐项测 POST/PUT/PATCH/DELETE、文件绑定、上传、确认、备货等越权路径均为 403；小程序误操作弹框；客户/师傅/经销商原有范围不变。
