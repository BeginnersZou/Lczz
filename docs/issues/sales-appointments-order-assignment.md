# 全栈：销售员预约、可选销售归属及订单增删改查

## 目标

- 销售员和经销商在小程序预约页都能从“销售人员（选填）”下拉列表选择平台现有可用销售员；管理员在 PC 创建/编辑订单时也可选填。
- 不选择即保存 `NULL`，销售员本人创建预约也不自动绑定自己。销售员只能查看自己创建或被明确指定的订单；A 创建并指定 B 时 A/B 均可查看。
- 订单创建人、订单来源、指定销售员三个概念分开保存、展示与审计。

## 技术范围

- `work_order.sales_user_id` 可空，外键/索引；新增销售预约来源与独立幂等记录，保留经销商旧接口兼容。幂等摘要包含可空 `salesUserId`。
- 独立候选接口分页/搜索可用 SALES，非管理员只给必要脱敏字段；写入时重新验证销售员可用。
- 后端销售员预约接口、管理员订单创建/编辑、经销商预约共同支持可空 `salesUserId`；订单列表/详情返回指定销售员与准确来源。
- PC 订单创建、查询、修改、作废及导出字段口径一致；归属变更可保留/替换/清空并记审计；作废保留历史。
- 小程序共用预约表单的销售员下拉支持加载、搜索、清空、空状态、失败重试及超出一页的候选。

## 验收

未指定、已指定、失效销售员、变更归属、幂等重试与冲突均有测试；销售员 A 自建并选 B 时 A/B 可读，其他销售员不可读；经销商不能看他人订单；订单附件与进度读取范围和订单读取范围一致，但无额外写权限。
